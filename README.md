# SOMMATRIX

**Genre:** Mathematical Logic Puzzle / Grid Puzzle

## Overview
SOMMATRIX is a logic puzzle game where the goal is to correctly identify which numbers in a grid contribute to the target sums for each row and column. The player must validate numbers that are part of the sum and eliminate those that are not.

## Features
- **Grid System:** Play on 4x4, 6x6, or 8x8 grids.
- **Target Sums:** Analyze rows and columns to match the required totals.
- **Interactive Gameplay:** Simple touch/click controls to Confirm or Cancel numbers.
- **Game Modes:**
    - **Standard:** Start with 3 Lives.
    - **Last Samurai:** A hardcore mode with only 1 Life.
- **Responsive Design:** Optimized for both desktop and mobile play.

## How to Play
1.  **Analyze**: Look at the target sums at the end of each row and column.
2.  **Confirm**: Click numbers to mark them as part of the sum (Green Check).
3.  **Eliminate**: Toggle to "Cancel" mode to mark numbers that should be ignored (Red Cross).
4.  **Win**: detailed logic and math skills are required to solve the full grid without running out of lives.

## Technical Details
This project is built using pure web technologies:
- **HTML5** for structure.
- **CSS3** for styling and responsiveness.
- **Vanilla JavaScript** for game logic and state management.

## Installation / Running Locally
No installation is required.
1.  Clone or download the repository.
2.  Open the `index.html` file in any modern web browser.
